# Contributing to amnesia

Thanks for your interest in contributing to amnesia — the privacy-first search engine.

## Quick Start

1. Fork and clone the repo
2. Create a branch: `git checkout -b my-feature`
3. Make your changes
4. Push and open a PR

## Guidelines

- Keep it simple — amnesia is intentionally minimal
- Privacy first — no tracking, no analytics, no cookies
- Test your changes locally before submitting

## Issues

Found a bug? [Open an issue](https://github.com/askalf/amnesia/issues/new).
