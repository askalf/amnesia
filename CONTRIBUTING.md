# Contributing to amnesia

Thanks for your interest in contributing to amnesia — the privacy-first search engine.

## Quick Start

1. Fork and clone the repo
2. Create a branch: `git checkout -b my-feature`
3. Make your changes
4. Test locally (HTML validation, scripts)
5. Push and open a PR

## Guidelines

- Keep it simple — amnesia is intentionally minimal
- Privacy first — no tracking, no analytics, no cookies
- Test your changes locally before submitting
- Do not add new dependencies without a clear reason
- Keep security in mind — this is a privacy tool

## Pull Requests

- All PRs must pass CI checks (HTML validation, scripts)
- Describe your changes clearly in the PR description
- Link any related issues

## Security Issues

**Do NOT open a public issue for security vulnerabilities.**

Please report security concerns to: security@askalf.org

See [SECURITY.md](SECURITY.md) for full details.

## Issues

Found a bug? [Open an issue](https://github.com/askalf/amnesia/issues/new).
